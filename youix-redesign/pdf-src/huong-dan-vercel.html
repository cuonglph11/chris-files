Deploy website youix.edu.vn lên Vercel

Hướng dẫn chuyển website sang host miễn phí trên Vercel — có 2 cách: nhờ Claude làm giúp (nếu chị có dùng Claude), hoặc tự làm thủ công từng bước trên trình duyệt, không cần biết code.

Thời gian: ~20–40 phút thao tác, cộng thời gian chờ tên miền cập nhật (vài giờ – 48 tiếng)
Chi phí: 0 đồng
Cần chuẩn bị: file index.html đính kèm, quyền quản trị DNS domain (PA Vietnam)
Soạn cho youix.edu.vn — 04/08/2026

⚠️ Đọc trước — để không mất email admin@youix.edu.vn

Website và email đang dùng chung tên miền youix.edu.vn nhưng có thể chạy trên hai hệ thống khác nhau. Trước khi đổi bất cứ thứ gì, hãy kiểm tra email đang chạy qua đâu:

  1. Vào mxtoolbox.com/MXLookup.aspx, gõ youix.edu.vn, bấm MX Lookup.
  2. Thấy google.com/googlemail.com → email đang qua Google, không liên quan hosting, an toàn để làm tiếp.
  3. Thấy tên khác (liên quan PA) → email đang chạy qua hosting hiện tại — dừng lại, không làm Bước 4 (trỏ domain) cho tới khi email được chuyển an toàn sang nơi khác trước.
  • File website đính kèm (index.html — 1 file duy nhất, không cần cài đặt gì thêm).
  • Một email bất kỳ để đăng ký tài khoản GitHub và Vercel (dùng Gmail cá nhân cũng được).
  • Tài khoản đăng nhập vào nơi quản trị domain youix.edu.vn hiện tại (thường là trang PA Vietnam).

1 Cách 1 — Nhờ Claude làm giúp

Mở Claude (Claude Code, Claude.ai, hoặc Cowork), đính kèm/upload file index.html mình gửi kèm, sau đó copy toàn bộ đoạn dưới đây rồi dán vào khung chat và gửi:

Prompt — copy toàn bộ đoạn bên dướiMình cần deploy một website tĩnh (chỉ có 1 file index.html, không cần build, không cần framework) lên Vercel, dưới tài khoản Vercel của mình. Yêu cầu: 1. Nếu bạn có công cụ/kết nối để deploy trực tiếp lên Vercel, hãy tạo project mới tên "youix" và deploy file index.html mình đính kèm lên môi trường production giúp mình. 2. Sau khi deploy xong, hướng dẫn mình cách thêm tên miền youix.edu.vn vào đúng project đó trong Vercel, và cho mình biết chính xác bản ghi DNS (A record hoặc CNAME) cần thêm vào nơi mình đang quản lý domain (PA Vietnam). 3. LƯU Ý QUAN TRỌNG: mình đang dùng chung tên miền này cho cả email (admin@youix.edu.vn), nên chỉ thêm đúng bản ghi cần cho website thôi — tuyệt đối không hướng dẫn mình xoá hay đổi bản ghi MX, và không dùng cách "chuyển toàn bộ DNS/nameserver sang Vercel quản lý". 4. Nếu bạn không có quyền/công cụ để deploy trực tiếp giúp mình, hãy hướng dẫn mình từng bước thật chi tiết, dễ hiểu, để mình tự làm trên trình duyệt (mình không biết code). 2 Cách 2 — Tự làm thủ công (không cần Claude)

Vercel không có kiểu "kéo — thả" trực tiếp như một số dịch vụ khác, nên cách đơn giản nhất không cần dùng dòng lệnh là: đưa file lên GitHub (kéo thả trên trình duyệt), rồi để Vercel lấy từ GitHub về.

Bước 1 — Tạo tài khoản GitHub

1
  1. Vào github.com/signup, đăng ký bằng email.
  2. Xác nhận email nếu được yêu cầu.

Bước 2 — Tạo kho chứa (repository) và tải file lên

2
  1. Sau khi đăng nhập, bấm dấu + ở góc trên bên phải → New repository.
  2. Đặt tên, ví dụ youix-website → chọn Public → bấm Create repository.
  3. Ở trang repository vừa tạo, bấm Add file → Upload files.
  4. Kéo file index.html vào ô upload, rồi bấm Commit changes ở cuối trang.

Bước 3 — Tạo tài khoản Vercel và deploy

3
  1. Vào vercel.com/signup, chọn Continue with GitHub để đăng nhập bằng tài khoản GitHub vừa tạo.
  2. Ở trang chính Vercel, bấm Add New... → Project.
  3. Tìm và chọn repository youix-website vừa tạo → bấm Import.
  4. Để nguyên các thiết lập mặc định (Vercel tự nhận diện đây là site tĩnh) → bấm Deploy.
  5. Đợi khoảng 30 giây, Vercel báo thành công và cho một link dạng youix-website.vercel.app.

Bước 4 — Kiểm tra link tạm

4

Mở link Vercel vừa nhận được, kiểm tra: trang hiện đúng nội dung, các mục menu chuyển được, link Facebook/Youtube/Figma mở đúng. Ổn thì làm tiếp Bước 5.

Bước 5 — Trỏ tên miền youix.edu.vn về Vercel

5
  1. Trong project trên Vercel, vào tab Settings → Domains.
  2. Gõ youix.edu.vn → bấm Add.
  3. Vercel sẽ hiện bản ghi DNS cần thêm — thường là các dòng như bảng dưới (luôn ưu tiên giá trị Vercel hiển thị trên màn hình nếu khác bảng này):
LoạiTên / HostGiá trị
A@ (để trống)76.76.21.21
CNAMEwwwcname.vercel-dns.com

⚠️ Rất quan trọng

Chỉ thêm đúng 2 bản ghi trên vào trang quản trị DNS ở PA Vietnam. Không xoá, không đổi bất kỳ bản ghi MX hay TXT nào đang có — đó là cấu hình email. Cũng không chọn phương án "chuyển nameserver sang Vercel quản lý toàn bộ".

Bước 6 — Chờ DNS cập nhật

6

Việc cập nhật DNS cần thời gian, thường vài giờ, có thể tới 24–48 tiếng. Trong lúc chờ, website cũ trên PA vẫn chạy bình thường, không ai bị gián đoạn.

Bước 7 — Kiểm tra lại cả web lẫn email

7
  1. Gõ youix.edu.vn trên trình duyệt → phải thấy website mới.
  2. Gửi thử 1 email tới admin@youix.edu.vn từ tài khoản khác → kiểm tra vẫn nhận được như trước.

Bước 8 — Huỷ gói hosting cũ (chỉ khi đã chắc chắn ổn)

8
  • Website hiển thị đúng bản mới, thử trên cả điện thoại và máy tính.
  • Email vào/ra bình thường như trước.
  • Đã chạy ổn định ít nhất 3–5 ngày không có vấn đề gì.

Đủ cả 3 điều trên mới vào PA Vietnam huỷ gói hosting trả phí — không huỷ phần tên miền/domain, vì cả website lẫn email vẫn cần domain đó.

? Câu hỏi thường gặp

Sau này muốn sửa nội dung website thì sao?
Vì đây là 1 file tĩnh, muốn sửa cần thay file index.html mới rồi lặp lại "Upload files" ở Bước 2 (GitHub tự cập nhật, Vercel tự deploy lại) — hoặc nhờ Claude làm theo Cách 1. Nếu cần tự sửa chữ/ảnh thường xuyên, nhắn lại để được tư vấn thêm.
Vercel miễn phí có giới hạn gì không?
Gói Hobby (miễn phí) của Vercel thoải mái dư cho một website hiển thị thông tin như YouIX, không phát sinh chi phí.
MX Lookup cho thấy email đang chạy qua PA thì sao?
Tạm dừng, chưa làm Bước 5 (trỏ domain). Nhắn lại để được hướng dẫn chuyển email sang nơi khác an toàn trước, rồi mới quay lại trỏ domain.
Lỡ làm sai ở bước nào thì có ảnh hưởng gì không?
Không sao — trước khi DNS cập nhật xong (Bước 6), website cũ trên PA vẫn đang chạy bình thường. Cứ nhắn lại bất kỳ lúc nào nếu vướng.

Tóm tắt nhanh: kiểm tra MX trước → GitHub upload file → Vercel import & deploy → kiểm tra link tạm → thêm domain trong Vercel + dán DNS ở PA (giữ nguyên MX) → chờ & kiểm tra lại → ổn định vài ngày mới huỷ gói cũ.
